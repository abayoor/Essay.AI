# Slipstream — спецификация продукта

Slipstream объединяет велосипедистов региона в одном спокойном и понятном сервисе. Первая готовая часть продукта помогает вести личный гараж, не забывать об обслуживании и сохранять маршруты.

## Технологии

- Vite + React + TypeScript + wouter;
- Supabase: авторизация и база данных;
- Vercel: автоматическая публикация после `git push`.

## Первая фаза

1. Email/password и Google-вход через Supabase.
2. Профиль райдера: имя, город, описание, фото.
3. Велосипеды: модель, тип, год, пробег и интервалы обслуживания.
4. Журнал поездок, автоматически обновляющий пробег велосипеда.
5. Маршруты: создание точками на карте, сохранение, просмотр дистанции и набора высоты.

## Следующие фазы

- групповые заезды и еженедельные челленджи;
- сегменты, лидерборды и отчёты об опасностях;
- календарь событий, маркетплейс и рекомендация маршрута.

Таблицы будущих фаз уже подготовлены в Supabase и защищены RLS. Интерфейс для них добавляется отдельными небольшими задачами.

## Дизайн

Фон — светлый туман `#EEF0EF`, карточки — белые, основной текст — графитовый `#1B2024`. Сигнальный акцент — глубокий бирюзовый `#1B8577`, природа — зелёный `#3E6F5C`, данные — стальной `#51637A`. Заголовки используют Archivo, текст — Inter, показатели — JetBrains Mono.
